# Contributing to Beacon

Beacon isn't accepting pull requests from outside contributors right now. A pull request from
outside the organization is closed with a comment. Issues are welcome: report a bug or ask for a
feature in the repository the issue is about.

| Repository                                                   | What the repository holds                                            |
| ------------------------------------------------------------ | -------------------------------------------------------------------- |
| [beacon.core](https://github.com/beacons-gg/beacon.core)     | the wire contract, the client SDK and the presets Beacon builds with |
| [beacon.server](https://github.com/beacons-gg/beacon.server) | the server, its Atlas toolchain and the five-flow driver             |
| [beacon.admin](https://github.com/beacons-gg/beacon.admin)   | the operator console and its plugin contract                         |

Each repository's `CONTRIBUTING.md` gives its setup and its checks, for anyone who builds the code
on their own machine. This page applies to a repository that has no guide of its own.

## Open an issue

- Search the open issues first. Add what you know to an existing issue instead of opening another.
- Choose the bug report form or the feature request form, and fill in every field the form asks
  for.
- Report a vulnerability privately as [`SECURITY.md`](SECURITY.md) describes. Don't open a public
  issue for one.
- Follow the [code of conduct](CODE_OF_CONDUCT.md) in issues and discussions.

For anything else, email `opensource@beacons.gg`.
